Please include as much detail as you can — a bug report is much easier to act on with the exact query, browser, and what you expected to see.

Reporting a bad answer

Cerebrum's answers are AI-generated summaries of retrieved abstracts. If you find one that's wrong — a wrong species, invented citation, misattributed finding — please email us with the exact question and a short description of the issue. This is how the system improves.

Security

If you've discovered a security issue, please email contact@askcerebrum.org with details. Please don't publicly disclose the issue until we've had a chance to respond.

Reputation and categorization

If your organization's web filter is blocking Cerebrum incorrectly, please email us — we can help you get it recategorized correctly (Educational / Reference).
